EXHIBIT № 03 / 07 · POSITIONING

What we are. What we are not.

+ WE ARE
  • A neutral notary for AI agent decisions.
  • An integrator of OpenLLMetry, OZ Merkle, and EAS.
  • A protocol — DR-1 is open and proposed for ISO/IEC 24970.
  • Plaid for AI agents · Carfax for AI decisions.
– WE ARE NOT
  • An insurance carrier — we don't underwrite.
  • A custodian — we hold no customer funds, ever.
  • A verdict provider — we don't decide who's at fault.
  • In this prototype, the operator_signature is signed by a key held by Ledgerline — production requires the customer to hold this key.
EXHIBIT № 04 / 07 · QUICKSTART

One SDK call.
That's the integration.

Drop into any AI agent that uses Anthropic, OpenAI, Gemini, LangChain, LlamaIndex, CrewAI, or a local Ollama. OpenLLMetry handles auto- instrumentation; we handle the audit ledger.

Verify a decision → See a live dashboard 
// CS Agent at Bloom Co. — 1 line of Ledgerline added
import Anthropic from '@anthropic-ai/sdk';
import { LedgerlineClient, DecisionRecordBuilder }
  from '@ledgerline/sdk';

const claude = new Anthropic();
const ledger = new LedgerlineClient({
  apiKey: process.env.LEDGERLINE_API_KEY!,
});

const response = await claude.messages.create({...});

const record = new DecisionRecordBuilder({
  agentId: 'bloom-cs-agent-v3',
  decisionClass: 'approve',
})
  .addLlmCall({ provider: 'anthropic', ... })
  .select({ output: response.content[0].text })
  .withRationale({ summary: 'within refund window' })
  .build();

await ledger.submit(record);
// → anchored on Base Sepolia in < 60s
EXHIBIT № 05 / 07 · FAQ

Two questions, asked twice a day.

Why blockchain, not a tamper-evident database?

A database is signed by the same party that runs it. In a refund chargeback, an FTC review, or a 식약처 audit, the operator's own log is — by legal definition — not third-party evidence. A Merkle root anchored on a public chain by an independent attester gives you a notary that no single party can rewind. SHA-256 collision bound is 2-128 by birthday — keccak256 the same. Mathematically immutable.

Why Base Sepolia, not mainnet?

This is a 9-day prototype submitted to a university competition. Sepolia attestations are functionally identical to mainnet; an EAS UID on Sepolia satisfies every architectural claim we make. Mainnet switchover is Phase 2 with a paying customer. Skipping it now means zero gas costs, zero key-management exposure on a live HSM. The attestation you see linked here is real.
